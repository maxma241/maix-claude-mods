# maix-claude-mods

我自己做的 Claude Code mods。每個子資料夾是一個 mod，這個 repo 本身是一個 marketplace。

## Mods

| Mod | 說明 |
| --- | --- |
| [turn-index](./turn-index) | 在輸入框上方列出這個 session 的每則 prompt，點一下跳回那個 turn |

## 安裝

在 terminal 版 Claude Code 的輸入框執行（第一次會問是否加入這個 marketplace，按 `y`，再選安裝範圍）：

```
/plugin install turn-index --marketplace maxma241/maix-claude-mods
```

或從 shell：

```
claude plugin install turn-index --marketplace maxma241/maix-claude-mods
```
